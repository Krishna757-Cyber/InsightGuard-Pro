# 🛡️ InsightGuard Pro

AI-Powered Intelligent Document Risk Analyzer using Microsoft Azure AI Services.

InsightGuard Pro is a futuristic web-based platform that analyzes uploaded documents using Azure Document Intelligence and Azure Content Safety APIs to detect risks, harmful content, suspicious phrases, policy violations, and structural anomalies.

Built with a premium glassmorphism UI, animated dashboards, real-time analytics, and enterprise-grade architecture.

---

# 🚀 Features

## 📄 Intelligent Document Analysis
- OCR-based document extraction
- Multi-format file support
- Structural document parsing
- AI-powered risk scoring

## 🛡️ Azure AI Integration
### Azure Document Intelligence
- Extract text from PDFs/images
- Detect forms, tables, layouts
- OCR confidence analysis

### Azure Content Safety
- Hate content detection
- Violence analysis
- Self-harm content detection
- Sexual content moderation

## 📊 Risk Analytics Dashboard
- Real-time risk gauge
- AI confidence score
- Safety metrics visualization
- Historical audit timeline
- Interactive charts

## ✨ Premium UI/UX
- Glassmorphism design
- Animated gradients
- Responsive dashboard
- Real-time notifications
- Smooth transitions & effects
