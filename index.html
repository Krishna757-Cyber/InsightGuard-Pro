🔑 Azure Configuration Guide

1

Create Azure Resources

Go to Azure Portal and create:

  • Document Intelligence (formerly Form Recognizer)
  • Content Safety resource
2

Get Credentials

In each resource's "Keys and Endpoint" section, copy:

  • Endpoint URL (e.g., https://xxx.cognitiveservices.azure.com/)
  • API Key (32-character string)
3

Configure InsightGuard

Paste credentials into the Azure Services tab or edit config.js:

AZURE: {
  DOCUMENT_INTELLIGENCE: {
    endpoint: 'https://YOUR_RESOURCE.cognitiveservices.azure.com/',
    key: 'YOUR_KEY_HERE'
  },
  CONTENT_SAFETY: {
    endpoint: 'https://YOUR_RESOURCE.cognitiveservices.azure.com/',
    key: 'YOUR_KEY_HERE'
  }
}
Production Security: Never expose API keys in client-side code. Use a backend proxy server with environment variables for production deployments.
